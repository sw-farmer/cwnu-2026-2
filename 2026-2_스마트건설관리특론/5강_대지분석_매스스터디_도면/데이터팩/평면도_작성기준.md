# 5회차 평면도 작성기준 (사전 배포)

> 수업 전에 한 번 읽어 오세요. 수업 중에는 이 파일을 AI에게 그대로 주고 "이 기준대로 기준층 평면도를 그려라"라고 지시합니다.
> 법정 수치는 법제처 원문으로 확인한 값입니다(2026-10-28 기준, 건축법·피난방화구조 규칙·장애인등편의법·소방시설법). 설계 가정은 법정값이 아니라 수업용 약속입니다.

## 2. 평면 구성 — 무엇을 넣나

기준층 평면 = **코어 + 사무실(거실) + 복도**

| 구성 | 넣을 것 | 설계 가정(수업 약속) |
|---|---|---|
| 계단실 | 직통계단 1개소(조건에 따라 2개소, 3절) | 계단실 약 3.0m × 6.0m, 단높이 18cm 이하·단너비 26cm 이상 |
| 승강기 | 승용 승강기 1대 | 승강로 약 2.4m × 2.4m + 앞 승강장 |
| 화장실 | 남·여 분리 + 장애인용 대변기(남·여 각 1) | 남·여 각 약 12㎡ 안팎 |
| 설비 | 전기(EPS)·통신(TPS)·배관(PS) 샤프트 | 합계 약 3㎡ |
| 사무실 | 나머지 면적 전부 | 창이 나는 외벽 쪽에 둔다 |
| 복도 | 코어와 사무실을 잇는 통로 | 짧게, 막다른 복도 최소화 |

- 코어는 **도로 반대쪽 또는 인접 건물과 붙는 쪽**에 두는 것이 보통입니다(창이 필요 없는 공간이므로).
- 전용률(사무실 ÷ 층 바닥면적)을 함께 계산해 표로 남깁니다.

### 도면 표현 — 기본계획 수준(벽 두께가 있는 도면)
선 하나로 벽을 그리는 단선 도면이 아니라, **벽 두께·기둥·문·창이 보이는 도면**으로 그립니다. 두께는 수업용 약속(설계 가정)입니다.

| 요소 | 그리는 방법 | 두께·크기(수업 약속) |
|---|---|---|
| 외벽 | 두 줄(이중선) + 잘린 면 채움(해치) | 300mm (철근콘크리트 200 + 단열·마감) |
| 코어벽(계단실·승강로) | 두 줄 + 채움 | 200mm 철근콘크리트 |
| 칸막이벽(화장실·실 구획) | 두 줄 | 100mm |
| 기둥 | 채운 사각형, 기둥 중심선(X1·X2…, Y1·Y2…) | 600×600mm, 간격 약 6~8m |
| 문 | 벽을 끊고 문짝 + 열림 호 | 사무실·화장실 0.9m, 피난계단 출입구 0.9m 이상(⑥) |
| 창 | 외벽 안에 세 줄 | 도로 쪽·후면 외벽 |
| 위생기구 | 대변기·소변기·세면대 기호 | 장애인용 대변기 칸 남·여 각 1(⑬) |
| 치수 | 기둥 중심선 기준 치수 + 전체 치수 | — |
| 단면도 | 슬래브·보·벽을 두께로, 잘린 면 채움 | 슬래브 200mm, 보 춤 600mm, 지하 외벽 300mm, 옥상 난간(파라펫) 1.2m(⑭) |

- 면적은 **벽·기둥 중심선**으로 잽니다(건축면적 = 외벽 중심선, 바닥면적 = 벽·기둥 중심선, 건축법 시행령 제119조제1항제2호·제3호).
- 층고는 바닥 구조체 윗면에서 위층 바닥 구조체 윗면까지입니다(같은 조 제8호).
- 보행거리(①)는 벽을 가로지르는 직선이 아니라 **복도를 따라 꺾이는 실제 경로**로 잽니다.

## 3. 도면에 숫자로 반영할 법정 기준

| # | 기준 | 수치 | 근거 |
|---|---|---|---|
| ① | 거실 각 부분 → 가장 가까운 직통계단까지 **보행거리** | **30m 이하**, 주요구조부가 내화구조면 **50m 이하** | 건축법 시행령 제34조제1항 |
| ② | 직통계단 **2개소 이상**이 필요한 경우(사무소 층) | 3층 이상인 층으로서 그 층 **거실 바닥면적 합계 400㎡ 이상** | 시행령 제34조제2항제4호 |
| ③ | 2개소일 때 두 계단 출입구 사이 거리 | 평면 최대 대각선의 **1/2 이상**(스프링클러 설치 시 1/3 이상) | 피난·방화구조 규칙 제8조제2항 |
| ④ | **피난계단** | **5층 이상** 층의 직통계단은 피난계단 또는 특별피난계단. 단, 내화구조이고 5층 이상 층 바닥면적 합계 200㎡ 이하이거나 200㎡마다 방화구획하면 제외 | 시행령 제35조제1항 |
| ⑤ | **특별피난계단** | **11층 이상** 층(바닥면적 400㎡ 미만 층 제외) | 시행령 제35조제2항 |
| ⑥ | 피난계단 구조 | 내화구조 벽으로 구획, 출입구 유효너비 **0.9m 이상**, 피난 방향으로 열리는 **60분(+) 방화문**, 돌음계단 금지 | 규칙 제9조 |
| ⑦ | 계단·계단참 **유효너비** | 바로 위층부터 최상층까지 거실 합계 **200㎡ 이상이면 120cm 이상**(그 밖 60cm 이상) | 규칙 제15조제2항 |
| ⑧ | 계단참·높이 | 높이 **3m 넘으면 3m 이내마다 너비 120cm 이상 계단참**, 계단 유효높이 **2.1m 이상**, 높이 1m 넘으면 양옆 난간 | 규칙 제15조제1항 |
| ⑨ | **복도 유효너비** | 그 층 거실 합계 **200㎡ 이상**: 양옆 거실 **1.5m 이상**, 그 밖 **1.2m 이상** | 규칙 제15조의2 |
| ⑩ | **승용 승강기** | **6층 이상 + 연면적 2,000㎡ 이상**이면 설치 의무(연면적은 지하층 포함). 단, **6층 건축물로서 각 층 거실 바닥면적 300㎡ 이내마다 직통계단 1개소 이상**이면 제외 | 건축법 제64조제1항, 시행령 제89조 |
| ⑪ | **비상용 승강기** | 건축물 높이 **31m 초과**이면 추가 설치 | 건축법 제64조제2항, 시행령 제90조 |
| ⑫ | **방화구획** | 연면적 1,000㎡ 초과 시: **매층 구획** + 10층 이하 층은 바닥면적 1,000㎡(스프링클러 3,000㎡) 이내마다 | 시행령 제46조, 규칙 제14조 |
| ⑬ | **장애인 편의시설** | 사무소 바닥면적 합계 **500㎡ 이상**: 주출입구 단차 제거, 장애인 출입 가능한 출입구·복도, **계단 또는 승강기**, **장애인용 대변기 남·여 각 1개 이상** 의무 | 장애인등편의법 시행령 별표 1·2 |
| ⑭ | 옥상 난간 | 옥상광장·2층 이상 노대 주위 **1.2m 이상** 난간 | 시행령 제40조제1항 |
| ⑮ | **스프링클러** | 층수 **6층 이상**이면 **모든 층** 설치 → 설치하면 ③은 1/3, ⑫는 3,000㎡ 기준 적용 | 소방시설법 시행령 별표 4 제1호라목1) |
| ⑯ | **옥내소화전** | 근린생활시설·업무시설 등 **연면적 1,500㎡ 이상**이면 모든 층 → 평면에 소화전함 위치 표시 | 같은 별표 제1호다목2) |
| ⑰ | **피난기구**(완강기 등) | 모든 층. 단 **피난층·지상 1·2층·11층 이상 층은 제외** → 이 건물은 3층부터, 평면에 위치 표시 | 같은 별표 제3호가목 |
| ⑱ | 유도등·소화기 | 피난구·통로유도등 설치, 연면적 33㎡ 이상 소화기 → 출입구·복도에 위치 표시 | 같은 별표 제1호가목·제3호다목 |

### 이 대지에서 미리 짚어 볼 점
- 기준층 바닥면적이 대지(약 485㎡)보다 작으므로 **거실 400㎡ 미만이면 직통계단 1개소**로 됩니다(②). 거실이 400㎡를 넘는지 꼭 계산합니다.
- 보행거리 50m(①)는 이 크기의 평면에서는 거의 문제가 안 됩니다. 그래도 **가장 먼 구석 → 계단 출입구** 거리를 도면에 치수로 표시합니다.
- 5층 이상이 되면 계단을 피난계단(④·⑥)으로, 높이 31m가 넘으면 비상용 승강기(⑪)를 넣어야 합니다. 6층까지는 거실 300㎡ 이내마다 계단이 있으면 승용 승강기 의무가 없고(⑩ 단서), 7층부터는 의무입니다. **층수를 한 층 올릴 때 코어가 커지는지**를 확인합니다.
- **6층이 되는 순간 스프링클러(⑮)가 모든 층에 필요**합니다. 5층안과 6층안의 차이를 체크표로 비교해 봅니다.

## 4. AI에게 줄 때 함께 요구할 것

1. 평면도 아래에 **법정 기준 체크표**(위 ①~⑱ 중 해당 항목: 기준값 / 도면값 / 적합 여부)
2. 보행거리 최장 경로를 복도를 따라 점선으로 표시하고 길이 기재
3. 벽 두께가 있는 도면(위 '도면 표현' 표) + 계단 너비·복도 너비 치수 표기
4. 실별 면적표(사무실·코어·복도)와 전용률
5. 근거가 확실하지 않은 수치는 지어내지 말고 **[확인필요]**로 표시

## 5. 이번 수업에서 다루지 않는 것
- 소방시설은 ⑮~⑱처럼 **설치 대상 여부와 위치 표시까지만**. 헤드 간격·수량 계산 등 화재안전기준 세부, 설비·구조 계산은 다루지 않음
- 실제 인허가에서는 관할 지자체 조례·지구단위계획·건축위원회 심의가 추가로 적용됩니다. 오늘 결과는 **학습용 검토안**입니다.
