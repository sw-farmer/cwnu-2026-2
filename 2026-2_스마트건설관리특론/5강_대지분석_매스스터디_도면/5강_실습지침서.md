# 5회차 실습지침서 — 대지 분석 → 최대 매스 → 도면 (상남동 4-2)

## 0. 준비 (수업 시작 때)
1. **.env**: 4회차처럼 `C:\dev\학번\.env`에 `LAW_OC=내OC값` 한 줄(법령 MCP는 지난 시간에 설치됨)
2. **데이터팩**: 내려받아 `C:\dev\학번\` 안에 `데이터팩5` 폴더로 풀기
   - `대지자료\` — 연속지적도 SHP · 건물정보 SHP(층수·높이·용도 속성 포함) · 주변현황 DWG(참고용: SHP가 낯선 분을 위해 같은 내용을 CAD로. 작업은 SHP만으로 가능)
   - `지구단위계획_결정조서_상남동4-2.png`, `지구단위계획_시행지침_제8조_허용용도.png`, `평면도_작성기준.md`, `과제_요약양식.md`
3. Claude 데스크톱 앱 → Code 탭 → 작업 폴더 `C:\dev\학번` 열기
4. 오늘 전제: **기존 건물(실제 6층 상가)을 철거하고 새로 짓는다.** 용도는 1층 근린생활시설 + 2층 이상 사무소

## 1. 실습 지시문 (채팅창에 그대로 입력)

| ③ 법규 표 | 지구단위계획 결정조서 캡처를 읽고, korean-law 도구로 창원시 도시계획 조례(일반상업 건폐율·용적률)와 창원시 주차장 조례(근생·업무 주차 기준)를 확인해서 outputs/법규표.md를 만들어 줘. 항목: 건폐율·용적률·높이·건축한계선·인접대지 이격·주차·정북일조 적용 여부. 둘이 다르면 어느 것이 적용되는지 적고, 마지막에 건축 가능 범위(후퇴선 안 면적, 최대 건축면적, 최대 연면적)를 계산해. 확인 못 한 것은 [확인필요]. | 건폐율 60%·용적률 400%·최저높이 12m·도로변 3m |
| ③-확인 | (법규표를 B장 기준표와 대조하고, AI가 물어본 것은 사람이 정해 준다. 미리 해 본 예) 매스 스터디는 기준 용적률 400%로 해. 600%는 시행지침 인센티브 조건을 채울 때만 쓰는 값이라 나중에 비교용으로만 볼게. 후퇴선 안 면적은 인접대지 0.5m까지 뺀 값으로 통일하고, 법규표의 건축 가능 범위를 그 기준으로 정리해 줘. | 400%/600% 결정, 후퇴선 면적 394㎡ 통일 |
