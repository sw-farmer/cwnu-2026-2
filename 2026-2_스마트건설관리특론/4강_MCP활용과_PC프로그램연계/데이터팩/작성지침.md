# 법규 검토서 작성지침 (제출용 문서)

## 1. 독자와 목적
- 독자: 건축주·발주 담당자·민원 담당 공무원. 법을 잘 모르는 사람도 **첫 쪽만 읽고 결론과 할 일을 알 수 있게** 쓴다.
- 결론을 먼저, 이유와 근거는 뒤에(두괄식). 법조문을 길게 옮기지 않고 **요건만 한 줄로** 풀어 쓴다.

## 2. 문서 구성 (이 순서·이 장 제목 그대로, 장은 4개)
| 순서 | 내용 |
|---|---|
| 표지 | 제목(대상 + "법규 검토"), 부제(무엇을 무엇으로), 작성일, 작성자 |
| 검토 요약 | 결론 4~6줄. 각 줄 = "항목: 결론 → 할 일" |
| Ⅰ. 검토 개요 | □ 검토 대상(위치·호실·면적) / □ 검토 범위(다섯 항목) / □ 대상지 현황(용도지역·지구 2~3줄) |
| Ⅱ. 검토 결과 요약 | 표 1개: 항목 · 결론 · 조치사항 · 근거 |
| Ⅲ. 항목별 검토 | 항목마다: □ 항목명 — 결론 한 줄 / ○ 판단 이유 1~2개 / ― 근거 조항 / ※ 확인 필요(있을 때만) |
| Ⅳ. 조치사항 및 확인 필요 사항 | □ 해야 할 일(누가·어디서) / □ 현장·관할 기관에 확인할 것 |
| 붙임 | 토지이용계획 열람 화면 1장 |

## 3. 표현 규칙
- **쓰지 않는 것**: 파일 이름·확장자(사례.md 등), 폴더 경로, 도구·프로그램 이름(MCP·API·Claude), "초안·변환 전" 같은 작업 상태, 내부 작업 메모
- 출처 표기는 본문 끝 한 줄로 충분: "※ 법령은 2026. 10. 27. 기준 국가법령정보센터 현행 조문으로 확인"
- 조항: 「건축법」 제19조제3항 / 「건축법 시행령」 별표 1 제3호나목 형식
- 날짜: 2026. 10. 27. 형식
- 결론 표현은 네 가지로 통일: **해당 / 비해당 / 불필요 / 확인 필요**
- 한 문단은 2줄 이내, 문장은 "~함", "~임" 개조식
- 확인하지 못한 것은 지어내지 않고 "확인 필요"로 쓰고, 누구에게(현장·구청 ○○과) 확인할지 적는다

## 4. 분량
- 본문 3~5쪽(표지·붙임 제외). 항목별 검토는 항목당 4~8줄.
