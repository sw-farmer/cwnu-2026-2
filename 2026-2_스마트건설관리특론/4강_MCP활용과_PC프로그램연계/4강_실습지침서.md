# 4회차 실습지침서 — MCP 활용과 PC 프로그램 연계 (법령 MCP로 법규 검토 × 한글 검토서)

## 0. 준비 (수업 전·수업 시작 때)
1. **법제처 Open API 키(OC)**: open.law.go.kr 가입 → [OPEN API 신청] → 승인 후 마이페이지 → API인증키관리의 "현재 API인증키(OC)" 확인
   - 신청서 "서버장비의 IP주소"에 이 키를 쓸 PC의 공인 IP를 넣는다(그 PC에서 네이버 "내 IP" 검색). 여러 개 등록 가능
   - 승인은 1~2일 걸릴 수 있다 → 미리 신청
2. **.env 만들기** — 키를 담는 한 줄짜리 파일
   - **어디에**: 지난 시간 만든 내 작업 폴더 `C:\dev\학번\` **바로 안**(CLAUDE.md 옆). 데이터팩이나 02_법규검토 폴더 안에 넣지 않는다.
   ```
   C:\dev\학번\
   ├─ CLAUDE.md        (2주차에 만든 규칙 파일)
   ├─ .env             ← 여기
   ├─ 데이터팩\        (3번에서 풂)
   └─ 02_법규검토\     (실습 ①에서 AI가 만듦)
   ```
   - **어떻게**: 메모장 열기 → `LAW_OC=복사한OC값` 한 줄(띄어쓰기·따옴표 없이) → [파일] → [다른 이름으로 저장]
     → 위치 `C:\dev\학번`, 파일 이름 `.env`, 파일 형식 **모든 파일(*.*)** → 저장
   - **확인**: 파일 탐색기 [보기] → [표시] → [파일 확장명] 켜기 → 이름이 `.env`인지 본다(`.env.txt`이면 이름을 `.env`로 바꾼다)
3. **데이터팩**: 내려받아 `C:\dev\학번\` 안에 `데이터팩` 폴더로 풀기
   - `토지이음_상남동4-2_①지정현황.png`, `토지이음_상남동4-2_②행위제한.png`, `가상_건물정보.md`, `템플릿.hwpx`, `작성지침.md`
4. Claude 데스크톱 앱 → Code 탭 → 작업 폴더 `C:\dev\학번` 열기

## 1. 실습 지시문 (채팅창에 그대로 입력)
| 단계 | 지시문 | 내가 확인할 것 |
|---|---|---|
| ① 폴더 | 02_법규검토 프로젝트 폴더를 우리 규칙대로 만들고 데이터팩을 sources에 넣어 줘. 오늘 최종 결과물은 outputs/법규검토서.hwpx야. 지금은 폴더만 만들고 결과물은 아직 만들지 마. | 폴더 구조(HANDOFF.md·sources·outputs) |
| ② 자료 읽기 | sources의 토지이음 캡처 2장과 가상_건물정보.md를 읽고 outputs/사례.md에 주소·용도지역·지구·건물 용도·면적·층을 표로 정리해 줘. 이미지에서 안 보이는 건 [확인필요]로 적고, 아직 법규 검토는 하지 마. | 캡처와 표가 맞는지, 대지면적 484.4㎡와 카페 면적 100㎡를 구분했는지 |
| ③ MCP 설치 | https://github.com/chrisryugj/korean-law-mcp 내용을 확인해서 법령 검색에 쓰고 싶어. 법제처 API 키(OC)는 이 작업 폴더의 .env에 LAW_OC로 넣어 두었어. 보안상 너는 .env를 직접 읽거나 쓰면 안 되고, 키는 MCP 프로그램이 스스로 읽게 설치해 줘. 법제처 API 조회는 허락할게. 설치가 끝나면 무엇을 했는지와 내가 할 일을 알려 줘. | AI가 알려 준 "내가 할 일"(세션 다시 열기·MCP 승인 등) 따라 하기 |
| ④ 연결 확인 | korean-law 도구로 건축법 제19조를 조회해서 연결이 되는지 확인해 줘. | 조문이 나오는지 |
| ⑤ 묻기 | 카페(휴게음식점)로 바꾸면 허가야, 신고야? outputs/사례.md 기준으로 근거 조항과 함께 알려 줘. (그 밖에 궁금한 것 자유롭게) | 답의 조항을 law.go.kr 원문과 대조 |
| ⑥ 검토 정리 | outputs/사례.md를 바탕으로 용도변경 절차·주차·장애인 편의시설·다중이용업소·영업신고 다섯 항목을 검토해서 outputs/법규검토.md에 정리해 줘. sources/작성지침.md의 구성과 표현 규칙을 따르고, 조항은 도구로 원문을 확인한 것만 써. 확인 못 한 것은 [확인필요]로 적어. 아직 한글 문서는 만들지 마. | 첫 쪽 요약만 읽어도 결론·할 일이 보이나, 파일명·도구명이 없나 |
| ⑦ 한글 문서 | outputs/법규검토.md를 sources/템플릿.hwpx 양식에 맞춰 outputs/법규검토서.hwpx로 만들어 줘. 작성자는 '건축공학전공 내 이름'으로 해 줘. 다 만들면 PDF로도 저장해서 쪽마다 모양을 확인해 줘. | 한글로 열어 표지·기호·표·그림·쪽번호가 템플릿대로인지 |

- 한글이 "접근 허용" 창을 띄우면 [모두 허용]을 누른다.
- 틀린 곳은 말로 고쳐 달라고 한다. 예: "다중이용업소 근거 조항을 원문에서 다시 확인해서 고쳐 줘."
