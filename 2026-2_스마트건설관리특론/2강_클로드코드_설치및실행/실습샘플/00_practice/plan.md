# 계획: 지상 15층 아파트 신축현장 3D 진도 대시보드 (공기 12개월)
1. 목표: 공정·인력·원가 가상 데이터를 만들고 월 슬라이더로 진도를 보는 단일 HTML 대시보드 제작
2. 데이터: `sources/schedule.csv` (공종,층,시작월,종료월,인원,원가_백만원) 40행 — 토공·기초, 골조 15개 층, 마감 15개 층, 설비·외장(층 구간 `1~5`), 옥탑·조경·준공
3. 집계 규칙: 원가는 시작~종료월에 균등 배분, 인원은 활동 중인 행의 합, 공정률은 원가 가중 누적
4. 변환: `_scripts/build_data.py` (표준 라이브러리만) → `outputs/data.js` (행 + 월별 집계)
5. 화면: `outputs/dashboard.html` 단일 파일, 다크 테마, 한 화면 격자 (3D / KPI / 간트 / S커브), 한국어
6. 3D: three.js(CDN) 15층 매스, 골조=주황·마감=청록, 마우스 드래그 회전·휠 줌
7. 간트: SVG 공종별 막대 + 현재 월 세로선 / S커브: Chart.js(CDN) 계획 누적원가
8. CSV 불러오기: 브라우저에서 같은 집계 로직으로 재계산 (UTF-8·엑셀 CP949 모두 지원)
9. 제약: 설치·외부 전송 없음, 파일은 `00_practice` 안에만 생성 (CDN은 라이브러리 로드용)
10. 검증: 스크립트 실행 결과와 브라우저 집계 일치 여부, 헤드리스 Chrome 화면 확인
