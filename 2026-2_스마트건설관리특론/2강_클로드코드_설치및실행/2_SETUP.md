# 2_SETUP.md — 작업 환경 셋팅 절차서 (Claude Code가 읽고 실행하는 파일)

<!-- v3 (2026-09-29): Windows 앱 리허설 반영 — PowerShell 권한 규칙 병기, 삭제=항상 묻기, /memory 대신 질문식 확인 -->

이 파일은 **Claude Code에게 주는 작업 지시서**임. 아래 단계를 **순서대로** 수행하고, 각 단계 끝에 "완료/실패 + 확인 결과"를 한두 줄로 보고할 것. 파일 생성·명령 실행 전에는 항상 승인을 받을 것(Manual 모드).

## 0. 절대 규칙 (전 단계 공통)
- 현재 열린 작업 폴더(예: `C:\dev\20261234` 또는 `C:\dev\smartcon`) **밖의 파일·폴더는 읽지도 쓰지도 않음.**
- **git 사용 금지.** `git init`·commit·저장소 생성 금지. Git은 설치돼 있어도 이 절차서에서는 사용하지 않음.
- **삭제 명령 금지**(`rm`, `Remove-Item`, `del`, `rmdir`). 정리가 필요하면 제안만 함.
- 인터넷으로 무엇을 **보내지 않음**(업로드·메일·API 전송). 설치 파일 다운로드만 허용.
- **관리자 권한이 필요한 명령 금지.** 필요하면 사용자에게 알리고 멈춤.
- 사용자 범위 설정(`C:\Users\...\.claude\`, `~/.claude.json`)은 **건드리지 않음.** 설정은 이 폴더 안에만 씀.
- 한국어·개조식으로 보고. 추측 금지, 확인 명령의 출력으로 판단.

## 1. 환경 확인
1. 현재 작업 폴더의 전체 경로 출력. 경로에 한글·공백이 있으면 경고.
2. 폴더 이름의 마지막 부분을 **작업자 이름**으로 기억(예: `C:\dev\20261234` → `20261234`).
3. 명령 실행 셸(Bash/PowerShell)과 Windows 버전 확인·보고.

## 2. Python 확인 → 없으면 설치
1. `python --version` 실행(안 되면 `py --version`).
2. **3.10 이상**이면 통과. 버전 보고.
3. 없거나 낮으면 "Python 3.12 설치 예정" 안내 → 승인 후 실행:
   ```
   winget install --id Python.Python.3.12 -e --source winget --scope user --accept-package-agreements --accept-source-agreements
   ```
   - winget 없음·실패 시: `https://www.python.org/downloads/windows/` 의 **Windows installer (64-bit)** 실행, 첫 화면 **"Add python.exe to PATH" 체크 → Install Now** 하도록 사용자에게 안내 후 대기.
4. 설치 후 `python --version` 재실행. **여전히 못 찾으면 정상**(새 PATH가 실행 중인 앱에 미반영). 아래를 안내하고 **여기서 멈춤**:
   > 앱을 완전히 종료 후 재실행 → 같은 폴더 열기 → "2_SETUP.md의 3단계부터 이어서 실행해" 입력.
5. `pip --version` 확인 후 3주차 데이터 실습용 패키지 설치:
   ```
   python -m pip install --user pandas openpyxl
   ```

## 3. 폴더 체계 만들기
현재 폴더 아래에 다음을 생성. 이미 있으면 건너뜀.
```
{작업 폴더}\
├── CLAUDE.md              ← 4단계 생성. 전체 체계 규칙(이 폴더 전체에 적용)
├── 00_practice\           ← 2주차 연습 프로젝트
│   ├── HANDOFF.md         ← 5단계 생성. 이 프로젝트의 상태·맥락·노하우
│   ├── sources\           ← 원본 자료(읽기 전용)
│   ├── _scripts\          ← 임시 파이썬 스크립트
│   └── outputs\           ← 산출물
└── _backup\               ← 수업 종료 시 백업 사본 위치
```

## 1. 언어·형식
- 항상 한국어, 개조식으로 답한다. 전문용어는 처음 나올 때 한 줄로 풀어 쓴다.

## 2. 폴더·파일 체계
- 프로젝트 폴더 이름: `NN_프로젝트명` (예: `01_공정관리_실습`). 새 프로젝트는 사용자 확인 후 만든다.
- 각 프로젝트 폴더 구조: `HANDOFF.md`(상태·맥락·노하우) / `sources/`(원본) / `_scripts/`(임시 코드) / `outputs/`(산출물)
- `sources/` 안의 원본은 절대 수정하지 않는다. 가공이 필요하면 `outputs/`에 사본을 만든다.
- 산출물 파일 이름: `내용_YYYY-MM-DD.md` 형식. 같은 날 여러 판이면 `_v2`, `_v3`를 붙인다.
- 임시 코드는 채팅에 인라인으로 실행하지 않고 `_scripts/`에 `.py` 파일로 저장해 실행한다.

## 3. 참조자료 다루기
- PDF·이미지·hwpx 등 원본은 처음 한 번 읽고 `outputs/`에 `원본명_요약.md`(본문 요약)와 필요 시 `.json`(표·수치)으로 정리한다.
- 이후 작업에서는 요약본을 먼저 읽고, 원문 확인이 꼭 필요할 때만 원본을 다시 연다.

<!-- ④ 작업 절차: 세션은 끊기므로 시작·종료 루틴을 고정. HANDOFF.md가 세션 사이의 기억 역할 -->

- 종료: `HANDOFF.md`의 상태 절(현재 단계·다음 할 일·미해결)을 갱신하고 사용자에게 백업을 상기시킨다.

## 6. 안전 설정 (이 폴더 안에만)
`{작업 폴더}\.claude\settings.local.json` 을 아래 내용으로 생성. `.claude` 폴더 쓰기는 보호 경로라 승인 창이 뜸 → "이 세션 동안 설정 편집 허용" 선택을 안내.
```json
{
  "permissions": {
    "defaultMode": "default",
    "ask": [
      "Bash(rm *)", "Bash(del *)", "Bash(rmdir *)", "Bash(Remove-Item *)",
      "PowerShell(Remove-Item *)", "PowerShell(rm *)", "PowerShell(del *)", "PowerShell(rmdir *)", "PowerShell(ri *)"
    ],
    "deny": [
      "Bash(git *)", "PowerShell(git *)",
      "Bash(curl *)", "Bash(wget *)",
      "PowerShell(curl *)", "PowerShell(wget *)", "PowerShell(Invoke-WebRequest *)", "PowerShell(Invoke-RestMethod *)",
      "Read(C:/Users/**)", "Edit(C:/Users/**)"
    ]
  },
  "autoMemoryEnabled": false
}
```
사용자에게 한 줄씩 설명: 삭제 명령은 **항상 묻기(ask)** — 사용자가 지시한 삭제는 승인 후 실행됨 / git·외부 전송 명령은 **차단(deny)** / Windows 앱은 명령을 PowerShell 도구로 실행하므로 `PowerShell(...)`과 `Bash(...)` 규칙을 함께 둠 / 사용자 홈 폴더 읽기·편집 차단(`Edit` 규칙이 모든 파일 쓰기 도구를 포괄, `Write(...)` 규칙은 무시됨) / 자동 메모리 끔(공용 PC 대비). CLAUDE.md의 "금지"는 AI에게 주는 지침이고, 이 파일은 프로그램이 강제하는 차단 → 이중 안전장치.
