# 수업 종료 정리 — 공용 PC에 내 자료·개인정보 남기지 않기

> 오늘이 마지막 실습입니다. **내 자료는 USB로 옮기고, 이 PC에서 내 작업 파일과 개인정보가 들어 있을 수 있는 것만 지웁니다.**
> Claude 앱·Git·Python은 다른 수업에서도 쓰므로 **지우지 않습니다.**
> 원칙: **AI가 먼저 목록을 보여 주고 → 내가 확인하고 → 지운다.** 처음부터 "다 지워"라고 하지 않습니다.

## 순서 한눈에

| 단계 | 누가 | 할 일 |
|---|---|---|
| 1 | 나 | USB 꽂기 |
| 2 | AI → 나 | 내 결과물을 USB로 복사 → 내가 USB에서 열어 확인 |
| 3 | AI → 나 | 이 PC에서 지울 것 **목록만** 만들기 → 내가 확인 |
| 4 | AI | 지금 지울 수 있는 것 삭제 |
| 5 | AI | 앱을 닫은 뒤 실행할 **마지막 정리 파일** 만들기 |
| 6 | 나 | 로그아웃 → 앱 종료 → 마지막 정리 파일 실행 → 확인 |

## 지시문 (Code 탭 채팅창에 그대로 입력)

| 단계 | 지시문 | 내가 확인할 것 |
|---|---|---|
| ② 백업 | 오늘이 마지막 수업이라 내 작업물을 USB로 옮기려고 해. C:\dev\학번 안에서 내가 만든 결과물(각 프로젝트의 outputs, HANDOFF.md, CLAUDE.md, 내가 만든 skill)을 USB의 `스마트건설관리특론_학번` 폴더로 복사해 줘. **.env(법제처 키)는 복사하지 마.** 다 되면 원본과 파일 수·크기를 비교해서 표로 보여 줘. | USB를 탐색기로 열어 hwpx·dwg 하나씩 열어 보기 |
| ③ 목록 | 이제 이 공용 PC에서 **내 작업 파일과 개인정보가 들어 있을 수 있는 것**을 지우려고 해. **아직 아무것도 지우지 말고 목록만** 표로 만들어 줘. 표 칸은 "위치 · 무엇인지 · 내 것인 근거 · 지금 지울지/마지막에 지울지/지우지 않음"이야. 찾아볼 곳: ① C:\dev\학번 전체(.env 포함) ② %USERPROFILE%\.claude 안에서 이 작업 폴더의 대화 기록·메모리, 내가 추가한 skill·plugin ③ 법령 MCP 등록(korean-law) ④ 다운로드·바탕화면의 수업 파일 ⑤ 한글·Windows 최근 문서 목록에 남은 내 파일 이름. **Claude 앱, Git, Python과 다른 사람의 폴더·기록은 '지우지 않음'으로 표시해 줘.** | 다른 사람 것·프로그램이 '지우지 않음'인지 |
| ④ 삭제 | 목록에서 '지금 지울' 것을 지워 줘. 휴지통을 거치지 않게 지우고, 하나씩 지울 때마다 결과를 표에 체크해 줘. 지금 열려 있는 작업 폴더와 이 대화의 기록처럼 **앱이 쓰고 있는 것은 '마지막에 지울' 것으로 남겨 둬.** | 오류로 못 지운 항목 |
| ⑤ 마지막 정리 파일 | 앱을 끈 뒤에 내가 실행할 정리 파일을 C:\Users\Public\final_cleanup.ps1로 만들어 줘(파일 이름은 영문, **UTF-8 BOM**으로 저장). 지울 것은 목록에서 '마지막에 지울' 것 전부와 휴지통 비우기, 그리고 **이 파일 자신**이야. 실행하면 지울 경로를 화면에 먼저 보여 주고 Y를 눌러야 지우게 하고, 끝나면 남은 경로가 있는지 확인해서 보여 주게 해 줘. 다 만들면 지우는 경로를 하나씩 설명해 줘. | 설명에 다른 사람 폴더나 프로그램 폴더가 없는지 |

## ⑥ 마지막 단계 (사람이 직접)

1. Claude 앱에서 로그아웃하고 앱을 완전히 종료합니다(작업표시줄 트레이 아이콘까지).
2. 시작 버튼 오른쪽 클릭 → **터미널(또는 Windows PowerShell)** → 아래 한 줄 입력 → 경로 확인 후 `Y`
   ```
   powershell -ExecutionPolicy Bypass -File C:\Users\Public\final_cleanup.ps1
   ```
   - "실행할 수 없습니다"(학교 PC 보안 정책)가 나오면 → ⑤에서 설명받은 경로를 탐색기로 직접 지우고 휴지통을 비웁니다.
3. 확인: 탐색기 주소창에 `C:\dev`를 넣어 내 학번 폴더가 없는지, `C:\Users\Public`에 final_cleanup.ps1이 없는지 봅니다.
4. 브라우저에서 claude.ai·GitHub·open.law.go.kr에 로그인했다면 로그아웃하고 브라우저 창을 모두 닫습니다.

## 지난 시간에 다른 PC를 썼다면
- 모든 PC를 다시 찾아가 지우기는 어렵습니다. 대신 **집에서** 아래 두 가지를 하면 남은 PC에서 내 계정·키를 쓸 수 없게 됩니다.
  - claude.ai → 프로필 → Settings → Account에서 **모든 기기 로그아웃**
  - 법제처 Open API(open.law.go.kr) 마이페이지에서 **강의실 IP 등록 삭제**(키가 남은 PC에서 더는 조회되지 않음)
- 그 PC를 다시 쓸 일이 있으면 위 ②~⑥을 그대로 하면 됩니다.

## 주의
- 계정에 올린 skill·채팅 기록은 PC가 아니라 **내 계정**에 남습니다. PC 정리와는 별개입니다.
