## 2. 실습 2 — 방금 과정을 skill로 만들고 불러 쓰기
> **skill** = 일종의 **절차서**. 프롬프트 한 장이 아니라 절차(SKILL.md) + 작성 기준·노하우(md) + 양식·견본(템플릿) + 반복 도구(py 스크립트)를 한 폴더에 묶은 것이다. 한 번 만들어 두면 다음부터 **긴 지시문 없이 한 줄로** 같은 순서·같은 품질로 진행한다.

| 단계 | 지시문 | 내가 확인할 것 |
|---|---|---|
| ⑦ skill 만들기 도구 받기 | https://github.com/anthropics/skills 의 skills/skill-creator 폴더를 이 작업 폴더의 .claude/skills/skill-creator 에 그대로 받아 줘. 받은 뒤 그 안의 SKILL.md 첫 부분을 읽고 무엇을 하는 skill인지 한 줄로 알려 줘. | .claude\skills\skill-creator\SKILL.md가 생겼는지 |
| 새 대화 | (앱에서 새 대화를 열고) 위 '새 대화' 지시문 | 대화를 나눠 사용량을 줄인다(받은 skill이 `/` 목록에 안 보이면 `/reload-skills`) |
| ⑧ skill 만들기 | skill-creator skill을 써서, 04_시공계획에서 한 ②~⑥ 과정(공사조건 md와 배치도 dwg를 받아 → 공정표 → 가설계획도 → 시공계획서 md → 한글 문서)을 재사용 skill로 만들어 줘. 과정은 HANDOFF.md와 _scripts를 보고 정리하고, 이름은 sigong-plan, 저장 위치는 이 작업 폴더의 .claude/skills/sigong-plan 이야. 템플릿·작성지침은 skill 폴더 안에 함께 넣어. 평가·비교 테스트는 생략하고 SKILL.md와 필요한 파일만 만들어. | SKILL.md의 설명(언제 쓰는지)과 단계 목록 |
| 새 대화 | (앱에서 새 대화를 열고) 위 '새 대화' 지시문 | |
| ⑨ skill 불러 쓰기 | /sigong-plan 04_시공계획/sources/공사조건_연습B.md 조건으로 05_시공계획_B 폴더에 공정표·가설계획도·시공계획서 hwpx·pdf까지 만들어 줘. | 긴 지시 없이 공정표·가설계획도·hwpx가 나오는지, B 조건(착공 9월 → 겨울 터파기·장마철 골조)이 날짜와 계절 대책에 반영됐는지 |

- ⑦·⑧에서 `.claude` 폴더에 파일을 써도 되는지 묻는 창이 뜨면 [허용]을 누른다(skill 폴더는 보호 폴더라 매번 묻는다).
- 창이 뜨지 않고 '권한이 없어 못 만들었다'고 하면: "같은 구조를 outputs/_skill에 만들어 줘"라고 다시 지시하고, 만들어진 폴더를 탐색기로 `C:\dev\학번\.claude\skills\`에 옮긴다.
- `/`를 치면 목록에 sigong-plan이 보인다. 이름을 몰라도 "시공계획서 skill로 만들어 줘"처럼 말로 불러도 된다.
- 결과가 마음에 안 들면: "sigong-plan skill에서 공정표 막대 색을 공종별로 다르게 하도록 고쳐 줘" → skill이 고쳐지고 다음부터 반영된다.
